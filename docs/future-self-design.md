# Future Self: ก้าวเล็ก ๆ ที่เข้ากับชีวิตจริง

ออกแบบใหม่ 18 กันยายน 2026 ตามคำขอนัตตี้

## ประสบการณ์ที่เปลี่ยนไป

หน้าเดิมให้เลือกคุณสมบัติหลายข้อโดยไม่มีขั้นตอนลงมือทำ และการ์ดหน้าหลักแสดงหลักฐานตัวอย่างตายตัว หน้าใหม่ให้เลือกหนึ่งเรื่องที่อยากให้ชีวิตเบาลง เลือกแผนที่แก้ได้ทุกคำ และกลับมาทบทวนจากสิ่งที่ลองจริง

- เริ่มด้วยสถานการณ์ที่เข้าใจง่าย: รับปากทั้งที่ไม่พร้อม, ซ้ำเติมตัวเองหลังพลาด, รีบตอบเมื่ออารมณ์แรง
- มี “ยังไม่รู้ ขอคุยให้เห็นภาพก่อน” สำหรับคนที่ยังบอกเป้าหมายไม่ได้ ปุ่มนี้เปิดบทสนทนาใหม่และเก็บแชทเดิมไว้
- แผน “ถ้า… ฉันจะลอง…” ระบุจังหวะกับการกระทำที่ผู้ใช้ทำเองได้ เป้าหมายไม่ใช่บังคับให้คนอื่นเปลี่ยน
- สำรวจภาพชีวิตที่อยากได้ อุปสรรค และก้าวสำรองได้ในรายละเอียดเสริม ไม่บังคับตอบครบ
- เลือกขนาดก้าวตามพลังวันนี้ และพักได้โดยไม่มี streak หรือการลงโทษ
- หลังลองตอบได้ว่าช่วย, ช่วยนิดหน่อย, ยังไม่เห็นต่าง, หรือยากขึ้น มีช่องข้อความที่เว้นได้
- “ยังไม่ได้ลอง” แยกจากผลหลังลงมือทำ ไม่อ้างว่าเป็นความสำเร็จ
- ประวัติเป็นบันทึกตามที่ผู้ใช้รายงาน ไม่มีเปอร์เซ็นต์ความเป็นคนที่ดีขึ้น ไม่มี XP หรือจำนวนลูปเพิ่มจากการติ๊ก
- โทนครีมและเขียวสงบ ลำดับภาพจากทิศทางที่เลือก → ก้าววันนี้ → สิ่งที่เรียนรู้ ใช้ปุ่ม native และช่องมี label

## หลักฐานและขอบเขต

อิง mental contrasting with implementation intentions (MCII): เชื่อมสิ่งที่อยากได้กับอุปสรรคจริงและแผนเมื่อเจอสถานการณ์ งานวิเคราะห์รวม 21 งานวิจัยพบผลต่อการบรรลุเป้าหมายระดับเล็กถึงปานกลาง (g = 0.336) และเตือนเรื่อง publication bias ผลอาจน้อยกว่าที่ประมาณไว้ การนำหลักนี้มาใช้ในหน้าจอเป็นการออกแบบประยุกต์ ยังไม่ใช่หลักฐานว่าแอปนี้มีประสิทธิผลเท่าการศึกษาหรือรักษาปัญหาสุขภาพจิตได้

แหล่ง: Wang, Wang & Gai (2021), https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2021.565202/full

## การเก็บข้อมูลรุ่นนี้

ผู้เข้าสู่ระบบเก็บแผนและบันทึกในบัญชีผ่าน API ที่ตรวจเจ้าของ มีสำเนาในเบราว์เซอร์และเก็บการแก้ไขรอส่งเมื่อเชื่อมต่อไม่ได้ โหมดทดลองยังเก็บในเครื่อง ผู้ใช้เลือกนำข้อมูลโหมดทดลองเข้าบัญชีได้เองโดยไม่ลบสำเนาเดิม บันทึกที่เพิ่มจากหลายเครื่องรวมตามรหัส ไม่เพิ่มซ้ำ หากแก้แผนชนกันให้เลือกแผนในเครื่องหรือแผนจากบัญชีโดยเก็บบันทึกทั้งหมดไว้ ไม่เปลี่ยนคะแนน ลูป หรือรางวัลเดิม

## การตรวจผลหลังใช้งานจริง

ต้องทดลองกับผู้ใช้เป้าหมายจริงก่อนกล่าวว่าได้ผล วัดจำนวนที่เลือกก้าวได้และกลับมารายงานว่าลองแล้ว การรายงานว่า “ช่วย” และ “หนักขึ้น” แยกจากยอดเปิดหน้า ดูอัตราที่ตอบ “ยังไม่รู้” แล้วไปต่อได้โดยไม่ถูกเร่ง แยกกลุ่มยังไม่มีโอกาสลอง ไม่ใช้จำนวนคลิกเป็นตัวแทนสุขภาพจิตที่ดีขึ้น
