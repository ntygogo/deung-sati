# ดึงสติ: Chat Beta → สมาชิกแบบชำระเงิน → App Store

วันที่วางแผน: 27 กันยายน 2026

อัปเดตรุ่นทดลอง: เพิ่มสิทธิ์ 14 วัน เริ่มเมื่อส่งข้อความแรก ตรวจจาก server ทั้ง local และ Vercel handler; หมดอายุแล้วหยุด AI แต่ยังเปิดประวัติได้ มีป้ายวันที่สิ้นสุด เตือน 3 วันสุดท้าย และบันทึกความสนใจอยากใช้ต่อในบัญชี ยังไม่จำกัดรายชื่อหรือใช้รหัสเชิญ และยังไม่มีการส่งอีเมลเตือนอัตโนมัติ

## รุ่นทดลองรอบนี้
- ใช้ฐาน main ที่มีการแก้ action guidance ล่าสุด ไม่ merge งานทดลอง 3D/DNA ทั้งชุด
- หน้าหลักใช้สีและห้องจาก Dreamy Home โดยใช้ภาพ mascot เดิมเป็นภาพประกอบ ไม่มีระบบเลี้ยงสัตว์
- สมัคร/ล็อกอินทุกครั้งที่ยังไม่มี session; เก็บประวัติบทสนทนาในบัญชี
- เปิด Home, Chat, ประวัติ/สรุปจากแชท และเครื่องมือพักใจที่เป็นส่วนหนึ่งของแชท
- ปิด onboarding ไข่, Companion, Future Self, notebook, journey, ร้านค้า และเมนูซื้อสมาชิก
- ฟีเจอร์ที่พักไว้ไม่ลบข้อมูล และป้องกันเส้นทางที่ปิดใน backend ด้วย
- CHAT_ONLY_BETA ใน src/shared/release.ts เป็นสวิตช์รุ่น การเปลี่ยนเป็น full ต้องมีการทดสอบก่อน deploy
- รอบนี้เป็น beta ฟรีที่ล็อกอินได้ แต่ยังไม่ได้จำกัดรายชื่อผู้ได้รับเชิญ
- ไม่มี analytics ใหม่หรือการเก็บข้อความเพิ่มเพื่อวิจัยในรอบนี้

## แผนทดลองที่เสนอ
เริ่ม 10–20 คน เป็นเวลา 7–14 วัน (ปรับตามจำนวนที่มีจริง)
ให้ลองกับเรื่องจริงที่สบายใจจะเล่า ไม่บังคับส่งประวัติแชทให้นัตตี้

เก็บ feedback สั้น ๆ หลังใช้:
1. ก่อนคุย/หลังคุย มองเรื่องที่เจอชัดแค่ไหน (0–10)
2. ตรงไหนรู้สึกว่า AI เข้าใจผิด ถามวน หรือแนะนำไม่ตรงชีวิตจริง
3. หลังคุยมีสิ่งเล็ก ๆ ที่อยากลองทำต่อหรือไม่
4. ถ้าไม่มีใครเตือน จะกลับมาใช้เมื่อไร เพราะอะไร

แยกผลเป็น: สมัครสำเร็จ / เริ่มคุย / คุยจบ / กลับมาใช้ / ข้อผิดพลาด / feedback
ตัวเลขใช้งานและต้นทุนต้องเพิ่ม event tracking ที่ไม่บันทึกข้อความส่วนตัว และแจ้งผู้ใช้ก่อน
อย่าใช้คะแนนความพอใจเป็นหลักฐานรักษาอาการหรือประสิทธิผลทางคลินิก

## ก่อนเริ่มเก็บเงิน
- ตรวจต้นทุน AI ต่อ active user โดยรวมคนใช้งานหนัก, hosting, payment/store fee, support และภาษีที่เกี่ยวข้อง
- เลือกแพ็กเกจหลักเพียงหนึ่งแพ็กเกจรายเดือน พร้อมสิทธิ์/โควตาชัดเจน
- ทดลองราคากับผู้ใช้จริง เช่น 99/149/199 บาท เป็นสมมติฐานสำหรับทดสอบ ไม่ใช่ราคาที่สรุปแล้ว
- ไม่เสนอ lifetime หรือ unlimited ก่อนเห็นต้นทุนระยะยาว
- แจ้งวันจบ beta และสิทธิ์หลังจบล่วงหน้า ไม่เปลี่ยนผู้ใช้ฟรีเป็นผู้เสียเงินอัตโนมัติ
- คงการอ่าน/ส่งออก/ลบข้อมูลไว้หลังสมาชิกหมดอายุ
- สร้าง entitlement ฝั่ง server ผูก user_id: plan, status, expires_at, provider, provider_subscription_id
- เชื่อม checkout + ตรวจลายเซ็น webhook + idempotency; รองรับหมดอายุ ยกเลิก คืนเงิน และ restore purchases
- ห้ามใช้ client-side isPlus/upgradePlus เป็นหลักฐานการชำระเงินจริง
- แยก config pricing จาก UI; reuse backend และ user identity ทั้งเว็บและแอพมือถือ

## เส้นทาง App Store
1. พิสูจน์ว่าคนกลับมาใช้เว็บก่อน จากนั้นประเมินโค้ดมือถือที่นำของเดิมมาใช้ต่อได้
2. ทำประสบการณ์มือถือให้สมบูรณ์: keyboard, safe area, loading/retry, history sync, accessibility
3. เตรียม privacy policy/data disclosure, consent สำหรับการส่งข้อมูลให้ AI, ลบบัญชี, support, screenshot และบัญชีสำหรับผู้ตรวจ
4. วางระบบ Apple In-App Purchase สำหรับบริการดิจิทัลตามข้อกำหนดประเทศ/หน้าร้านที่จำหน่าย ตรวจเงื่อนไขปัจจุบันอีกครั้งก่อนส่ง
5. ทดสอบผ่าน TestFlight ก่อนส่ง App Store review; การห่อเว็บอย่างเดียวไม่รับประกันผ่านเกณฑ์ minimum functionality

Apple Developer Program ปัจจุบัน 99 USD/ปีหรือสกุลเงินท้องถิ่นที่รองรับ ยังไม่รวมค่าพัฒนา/โฮสต์/AI/ค่าธรรมเนียมการขาย
ข้อมูลอ้างอิงที่ตรวจวันที่วางแผน:
- https://developer.apple.com/programs/whats-included/
- https://developer.apple.com/app-store/review/guidelines/
- https://developer.apple.com/testflight/

## เกณฑ์ตัดสินใจไปต่อ
- ปัญหา login, ข้อมูลหาย, ข้อมูลข้ามบัญชี และความเสี่ยงจากคำตอบได้รับการแก้ก่อนเพิ่มจำนวนผู้ใช้
- มีคนกลับมาใช้ด้วยตัวเอง และอธิบายประโยชน์ที่ได้จริง
- มีคนยอมซื้อในราคาใกล้เคียงที่ทดสอบ พร้อมต้นทุนต่อสมาชิกที่รับไหว
- App Store เป็นช่องทางเข้าถึงเพิ่ม ไม่ใช่เงื่อนไขว่าต้องมีจึงเริ่มหารายได้ได้
